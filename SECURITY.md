# Security policy

GitDesk is in early development. Security fixes are applied to `main`; no released version is currently supported.

Please report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/michaeldadi/GitDesk/security/advisories/new). Include a minimal reproduction using a disposable repository and the GitDesk version or commit. Do not post credentials, private repository contents, or an exploit in a public issue.

GitDesk currently uses the system Git executable and produces an ad-hoc signed development app. The build in this repository is not notarized for public distribution. Before using GitDesk on valuable repositories, keep a backup and verify the Git operation you intend to perform.
